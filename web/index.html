Advanced: protocol, console and capture decoder

Print protocol (this device’s Bluetooth)

Decoded from the Kodak app. Each label is 12 zero bytes and 10 ff f1 02, an ESC/POS raster image, then 1d 0c and 10 ff f1 45. The printer answers aa when the label is done. The print server uses the same protocol.

Image data

Placeholders: {bpl}, {lines16}, {lines16be}, {lines}, {dots16}, {copies}.

Decode a Bluetooth capture

Record the Kodak app printing one short label, then open the log here. You get every byte the app sent, a bitmap view to spot the image, and a replay button to prove the bytes work from this page.

How to capture

Android

  1. Settings → About phone → tap Build number seven times.
  2. Developer options → Enable Bluetooth HCI snoop log → Enabled. Turn Bluetooth off and on.
  3. In the Kodak app, print one label with short, bold text such as AB.
  4. Developer options → Take bug report. In the zip, open FS/data/misc/bluetooth/logs/btsnoop_hci.log.

iPhone (needs a Mac)

  1. Install Apple's Bluetooth logging profile on the iPhone (developer.apple.com → Bug Reporting → Profiles and Logs).
  2. On the Mac, open PacketLogger (Additional Tools for Xcode) → File → New iOS Trace.
  3. Print one label from the Kodak app, then save the trace as .pklg.
